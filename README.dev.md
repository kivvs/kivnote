# 记事本 · 万能文件查看器 v1.6.0（开发文档）

> 面向最终用户的使用说明见 `使用说明.md`。作者：kivvs，个人使用免费，禁止商用。

深色 macOS 风格的多标签记事本：能打开大部分文件类型，任何文件都能在**正常 / 十六进制 / 二进制**三视图之间切换，表格可编辑、PDF 可提取文本。

## 直接使用

双击 `release/Notepad-1.6.0-portable.exe`（免安装）。
右键「发送到 → 桌面快捷方式」可以放到桌面。

## 界面

```
┌────────────────────────────────────────────────────────┐
│ ● ● ●   doc.pdf - 记事本          ● ● ●（右上窗口钮）  │
├────────────────────────────────────────────────────────┤
│ ＋ 📁 ⤓ │ 正常|十六进制|二进制 │ 🔍 │ 标签条… ＋ │ ↗ ⋯ │
├────────────────────────────────────────────────────────┤
│  正文 / 预览 / 字节视图 / 表格                          │
├────────────────────────────────────────────────────────┤
│ ══════════════════════════════════════════════════════ │
│ 行 1，列 1  266 字符  10 行   正常 文本 569 B UTF-8    │
└────────────────────────────────────────────────────────┘
```

- 左上三个灰点：装饰（跟 macOS 一致）
- 右上三个彩点：黄 = 最小化，绿 = 最大化，红 = 关闭
- 标签条在导航栏中间，当前标签高亮，`×` 关闭，最右 `＋` 新建

## 多标签

| 操作 | 快捷键 |
|---|---|
| 新建标签 | `Ctrl+T` / `Ctrl+N` |
| 关闭标签 | `Ctrl+W`，或点标签上的 `×` |
| 前后切换 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |

每个标签独立保存：内容、光标、滚动位置、视图模式、字节改动、表格改动。
标签上的橙点 `●` 表示未保存。一次拖入多个文件会各开一个标签。

## 三视图

| 视图 | 内容 |
|---|---|
| 正常 | 文本可编辑 / 图片 / 音视频 / PDF / 表格 |
| 十六进制 | 每行 16 字节：偏移 + 字节 + ASCII，**可编辑** |
| 二进制 | 每行 8 字节：0/1，`1` 绿色高亮（只读） |

`Ctrl+E` 循环切换。按块读取，每次 64 KB，滚到底自动续读。

## 十六进制编辑（010 风格）

1. 点一个字节 → 青色光标框
2. 敲十六进制数字 → 高 4 位 → 低 4 位，输满自动跳到下一个字节
3. 改过的字节显示**橙色**
4. `←→↑↓` 移动（上下按 16 字节整行）、`Home`/`End`/`PageUp`/`PageDown`
5. `Ctrl+S` 写回原文件 —— 只写被改的那几个字节（`r+` 随机写），大文件也瞬间完成

## 表格（可编辑）

支持 `.xlsx .xlsm .xls .csv .tsv .ods`，渲染成真正的表格。

**读**

- 表头自动识别（首行全非数字就当表头），否则显示 `A B C` 列号
- 左侧行号固定，数字列右对齐并绿色区分
- 多工作表顶部切换
- CSV 的 UTF-8 / GBK 自动识别
- 单表最多 2000 行 × 120 列

**改**

| 操作 | 方式 |
|---|---|
| 选中单元格 | 单击（青框） |
| 编辑 | 双击，或选中后回车 |
| 提交 | `Enter` 留在原格 / `Tab` 跳到右格 |
| 取消 | `Esc` |
| 插入行 | `↑+行`（上方）/ `↓+行`（下方） |
| 删除行 | `−行` |
| 插入列 | `←+列`（左侧）/ `→+列`（右侧） |
| 删除列 | `−列` |
| 改列宽 | 拖表头右边缘的窄条 |
| 重算列宽 | `自适应` |
| 保存 | `Ctrl+S` |

保存时：
- `.csv` / `.tsv` 重新序列化写回（引号、逗号、换行都正确转义）
- `.xlsx` 用 SheetJS 重建改动过的工作表再写回

⚠️ **限制**：xlsx 写回会丢样式（字体颜色、合并单元格、图表、公式结果），只保留单元格的值。要保留排版请在 Excel 里改。

## Word 文档

`.docx` 是 zip + XML。主进程用 adm-zip 取出 `word/document.xml`，渲染进程用 `DOMParser` 解析：

- `w:p` + `w:pStyle` → `h1`–`h6` / `p`
- `w:r` + `w:rPr` 的 `w:b/w:i/w:u/w:strike` → `b/i/u/s`
- `w:numPr` → 圆点列表
- `w:tbl` → `<table>`
- `w:drawing` → `[图片]` 占位

只读。`.doc`（OLE 复合文档）不支持，提示另存为 `.docx`。

## PDF

PDF 是版式文档，正文没有"段落"概念，做不到像 Word 那样直接改字。
能做的：菜单 `⋯ → 提取 PDF 文本到新标签`，把文本层抽成可编辑的文本标签：

```
════════ 第 1 页 ════════
Hello from Notepad PDF Viewer
This is a generated test page.
```

可以继续编辑、查找、另存 `.txt`。扫描件会提示"这一页没有文本层"。

## 能打开什么

| 类型 | 后缀（部分） | 正常模式 |
|---|---|---|
| 文本 | txt md json xml yaml py js go rs c cpp java sql sh bat ps1 log ini conf … | 可编辑可保存，UTF-8 / GBK 自动识别 |
| 表格 | xlsx xlsm xls csv tsv ods | 表格视图，可编辑 |
| Word | docx docm dotx | 文档视图（标题/粗斜体/列表/表格） |
| 图片 | png jpg gif webp bmp ico svg tiff avif | 居中预览 |
| 音频 | mp3 wav flac ogg m4a aac opus | 内嵌播放器 |
| 视频 | mp4 webm mkv mov avi m4v | 内嵌播放器 |
| PDF | pdf | 内嵌阅读器 + 文本提取 |
| 其它 | zip rar 7z exe dll docx pptx iso … | 提示卡片 + 引导去字节视图 |

**后缀写错也能认**：判定顺序是 文件头（魔数）→ 后缀 → 内容嗅探。

## 发给别人之前要知道的

程序**没有代码签名**（个人开发者签名证书要几千块一年），所以别人第一次运行时会被拦一下：

| 现象 | 原因 | 对方要做的 |
|---|---|---|
| 蓝色窗口「Windows 已保护你的电脑」 | SmartScreen 对未签名 exe 的默认拦截 | 点「更多信息」→「仍要运行」 |
| 杀软报毒 / 隔离 | Electron 打包程序的常见误报，portable 自解压版更容易触发 | 加白名单，或用 zip 绿色版 |
| 首次启动慢几秒 | Defender 在扫描新文件 | 等着就行 |

**两个发行版本，推荐 zip 版：**

| 文件 | 说明 |
|---|---|
| `Notepad-1.6.0-portable.exe`（75 MB） | 单文件，双击即用。启动时自解压到临时目录，企业管控环境可能失败 |
| `Notepad-1.6.0-win64.zip`（123 MB） | 解压到任意目录，运行里面的 `Notepad.exe`。**更稳，杀软误报也少** |

其它：

- 只支持 **Windows 10 / 11 x64**（ARM64 机器需要另打）
- 不依赖 .NET / VC++ 运行时，Electron 自带
- **不注册文件关联**：不会接管 `.txt` 双击。要么先开软件再打开文件，要么把文件拖进窗口
- 免费商用无所谓，但别指望有技术支持

## 开发

```bash
npm install
npm start            # 开发运行
npm run dist         # 打包
```

**环境坑**

1. `ELECTRON_RUN_AS_NODE=1` 会让 Electron 退化成纯 Node，报
   `Cannot read properties of undefined (reading 'handle')`。
   用 `env -u ELECTRON_RUN_AS_NODE` 启动。
2. 无 GPU / 远程桌面 / 虚拟机上，Chromium 自带 PDF 阅读器会白屏。
   程序默认 `disable-gpu-compositing`；仍不行加 `--disable-gpu`。
3. 打包时若报 `app.asar: being used by another process`，说明旧实例没退干净，
   换个输出目录或杀掉残留进程。
4. 调试参数：`--shot`（截图后退出）、`--open=路径`（可多次）、
   `--view=hex|bin`、`--table-test`、`--pdf-test`。

## 结构

```

preload.js           contextBridge 暴露给渲染进程的 API
renderer/index.html  整个界面（样式 + 逻辑，单文件）
renderer/sheetjs.js  SheetJS（表格解析/写回）
build/icon.ico       图标
testfiles/           测试文件（png / pdf / zip / xlsx / csv / gbk / 后缀伪装）
```
